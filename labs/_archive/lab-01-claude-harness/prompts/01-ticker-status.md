# Lab 01 prompt — ticker status

คุณเป็น frontend agent ของ Paper Crypto Trade Desk

1. โหลด skill `paper-only`
2. อ่าน `apps/trade-desk/frontend/src/App.jsx`
3. ทำให้ผู้ใช้เห็นสถานะฟีด (`live` / `fixture` / error) ชัดขึ้นบน UI โดยไม่แก้ backend
4. ตรวจบน http://localhost:4173
5. สรุปสั้นๆ ว่าแก้ไฟล์ไหน และผู้เรียนควรเห็นอะไรบนจอเขา
6. หยุดแล้วรอผู้เรียนสั่งต่อ — อย่าทำทั้งเดสก์ให้จบในพรอมต์เดียว
