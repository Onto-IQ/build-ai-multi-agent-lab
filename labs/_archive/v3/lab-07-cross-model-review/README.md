## ทำไมต้องสองเครื่องมือ

- ความเห็นคนละโมเดลลดจุดบอด
- คุมต้นทุน (โมเดลถูกกว่าไปรีวิว)
- ไม่ใช่การสร้าง harness แข่ง — เป็น one-shot CLI
