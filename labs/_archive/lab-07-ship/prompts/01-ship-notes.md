# Lab 07 prompt — ship notes

ช่วยผู้เรียนร่างบันทึกการ ship สั้นๆ

ต้องมี:

- URL สาธารณะจริง (ให้ผู้เรียนเป็นคนวาง — ถ้ายังไม่มี ให้เขียนว่ายังไม่ ship)
- สิ่งที่ทำได้บน Trade Desk
- สูตรพกกลับ: skill + agent + CLI ข้ามเครื่องมือ + Agent View + Command Center
- สิ่งที่ต่างจากเพื่อน (ถ้ามี) โดยยังอยู่ใน paper-only

ห้ามประดิษฐ์ URL  
ห้ามบอกว่าเทรดจริง

ผู้เรียนเป็นคนโชว์แข่ง — อย่าร่างให้ฟังเป็นของกลางของห้อง

---
