# Lab 05 prompt — fallback Subagents

Agent Teams ไม่ขึ้นบนเครื่องนี้ — ใช้ Subagents แทน

1. สปอน frontend subagent ให้ต่อ order ticket + history
2. สปอน reviewer subagent ให้อ่านผลแล้วรายงาน
3. ผู้เรียนต้องเห็นงานขนานใน `/agents` หรือผลสรุปกลับมาหลายชิ้น
4. ทำต่อหลาย turn จนส่ง paper order ได้หรือหมดเวลาแล้วยังรายงานช่องว่างชัด
5. รอผู้เรียนเป็นคนสั่งเทิร์นถัดไป

---

นี่คือ**โครงเริ่ม** ไม่ใช่คำตอบสำเร็จรูป  
ผู้เรียนสั่งต่อเองบนเครื่องเขา อย่านั่งดูจอวิทยากรแล้วถือว่าผ่าน
