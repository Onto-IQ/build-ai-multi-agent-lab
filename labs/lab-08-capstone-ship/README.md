## ได้รับมาจาก Lab ก่อน

ครบสูตร harness · swarm · cross-model review

## ได้เพิ่มใน Lab นี้

feature ส่วนตัว · merge · **URL สาธารณะจริง** · โชว์แข่ง

## ขั้นตอน

1. เขียน/ขยาย issue ของคุณเองให้มีเกณฑ์ผ่านชัด
2. ใช้ workflow เต็ม: Plan → multi-agent Build → Test → review → Ship
3. แหล่งข้อมูลที่ใช้ได้: `@actual-app/api` / community Actual MCP / public API (เช่นอัตราแลกเปลี่ยน) / fixture CSV — ไม่ใช้ credential จริง
4. Deploy ตามที่เลือก: PikaPods / Fly.io สำหรับ Actual หรือหน้า capstone static บน Vercel (ต้องผ่านวิทยากร)
5. พรอมต์ [`prompts/01-capstone.md`](prompts/01-capstone.md)
