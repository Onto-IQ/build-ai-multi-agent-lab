# Prompt — Coolify deploy helper (Lab 08)

คัดลอกเฉพาะบล็อกด้านล่างไปวางใน `claude`  
**(กด Deploy ใน Coolify / curl จริง — ตาม README กับวิทยากร)**

```text
เป้าหมาย: ช่วยเตรียมและบันทึกหลักฐาน deploy ไป https://<STUDENT_SLUG>.9expert.online

อ่าน .env เฉพาะชื่อ key ที่เกี่ยวกับ SITE_URL / STUDENT_SLUG / PORT / DATA_DIR — อย่าพิมพ์ค่า secret ในแชท

ช่วย:
1. สรุปรายการ env ที่ต้องใส่ใน Coolify (ชื่อ key เท่านั้น)
2. ร่าง docs/SHIP.md: URL, วันที่, คำสั่ง curl ตรวจ homepage และ POST contact/guestbook
3. เตือนถ้ายังไม่มีหลักฐาน HTTP 200 จริง — ห้ามเคลม ship สำเร็จ

Demo อ้างอิงของห้อง: https://demo.9expert.online — ไม่ใช่ URL ของฉัน
ห้ามขอหรือบันทึก webhook / admin password
```
