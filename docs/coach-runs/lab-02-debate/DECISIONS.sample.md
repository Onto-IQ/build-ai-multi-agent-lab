# DECISIONS — Personal Branding Site

Final decisions for v1, resolving the debate in [DEBATE.md](DEBATE.md), based on [PROFILE.md](PROFILE.md). Date: 2026-09-23.

- **Pages — build all five, each with exactly one job:** Home (hero states the demos → dependable-systems promise plus a single CTA to Contact), About (practitioner credibility and the bio from PROFILE.md), Interests (five fixed cards, one per PROFILE.md interest — replace, never accumulate), Contact (≤ 4-field form, stated response time, mailto fallback), Guestbook (moderated sign-the-logbook list).
- **Visual tone — calm, technical, anti-hype:** minimal restrained palette, generous whitespace, system fonts or a single webfont, dark mode, WCAG AA contrast, mobile-first, near-zero JavaScript, LCP target under 2.5 s. No AI clichés (glowing brains, gradient robots, "revolutionary" copy) anywhere.
- **Must-have API features — a small, guarded surface only:** Guestbook `GET` (published entries, paginated) and `POST` (validated: name ≤ 60 chars, message ≤ 500 chars, optional URL; per-IP rate limiting; moderation queue before publish; outbound links rendered `rel="nofollow noopener"`), plus a Contact form `POST` with the same validation and rate-limit treatment delivering to email. Nothing else is exposed.
- **Content source — PROFILE.md is the single source of truth:** name, headline, bio, audience, and interests are derived from `docs/PROFILE.md`; site copy is never hand-duplicated. All bio/content changes happen in PROFILE.md and propagate to the site (refreshed at least quarterly so nothing goes stale).
- **What NOT to build (v1):** no blog or CMS, no comment threads (the Guestbook is not comments), no user accounts or auth, no AI chatbot widget, no workshop payment or booking engine, no analytics beyond a lightweight page counter, no bilingual site (English only, with one deliberate Thai note in About), no testimonial carousel until real testimonials with permission exist, and no client-side framework heavier than the contact form and guestbook require.
